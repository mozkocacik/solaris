# TagChip

Tag chips show free-form labels that users add to objects.

## Anatomy
`.sl-tag`: 20px, `r-sm`, 1px `border`, `surface-2`, `fs-xs`, `text-2`. Wrap several in `.sl-tags` (gap `space-4`, wraps).

## Rules
- Tags are neutral. They never use category or status tints, so they do not compete with type and status.
- Add tags with a small dashed add chip; remove them in edit mode with an `x` button inside the chip.
