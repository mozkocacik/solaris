# ScreenObject

Reference screen: the object view of one item, with the item canvas and a right panel for Comments, Versions and Activity.

## What to try
- Switch the panel tabs.
- Back (arrow) returns to the collection with its details panel; Open there comes back here.
- Share opens the share dialog; ⋯ opens the more-actions menu.
- Switch the theme in the top bar.

The canvas draws the item as a page with a table. Products put their real editor or renderer on the same `bg` canvas.
