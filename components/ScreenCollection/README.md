# ScreenCollection

Reference screen: a collection shown as a table, with the details panel open beside it.

Use it as the model for every list screen. It combines AppShell, Sidebar, TopBar, SegmentedTabs, FilterChip, SortButton, Table, GridCard (switch the view), DetailsPanel, BulkBar (check rows), Toast (Import), ShareDialog (Share) and the object view (Open).

## What to try
- Click a name to change the details panel; Open goes to the object view, and Back returns.
- Check two rows: the bulk bar rises at the bottom centre.
- Switch table / grid in the header; switch the theme in the top bar.
- Import shows the upload toast; Share opens the share dialog.

All names and figures are neutral sample data.
